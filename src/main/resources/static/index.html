Gestor de Período

  • /periodo - Exibe o período atual
  • /periodo/inicial - Exibe a data inicial
  • /periodo/final - Exibe a data final
  • /periodo/atualizarInicial - Atualiza a data inicial (necessário Body)
  • /atualizarFinal - Atualiza a data final (necessário Body)
  • /periodo/quantidade - Exibe quantidade de dias
  • /periodo/distribuicao - Exibe distribuição de dias
  • /periodo/detalhado - Exibe período detalhado
